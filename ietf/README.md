# GTS v2 standards review

The [GTS v2 specification](../docs/GTS-SPEC.md) is the project's normative review text.
[P1](../docs/v2/P1.md) defines the CBOR wire format, [P2](../docs/v2/P2.md) assigns its codes,
and [P7](../docs/v2/P7.md) defines reader results and conformance claims. [P3](../docs/v2/P3.md)
defines the RDF dataset projection.

The project publishes [Implementer Draft 1](https://github.com/Blackcat-Informatics/gmeow-gts/releases/tag/spec-v2-draft-1)
for public review. Cite the part, requirement or section and commit in feedback.
