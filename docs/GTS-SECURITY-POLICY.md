# GTS v2 security

[P5](v2/P5.md) defines durability and proofs, [P6](v2/P6.md) defines signature verification, and [P8](v2/P8.md) defines sealing. Applications relying on these results should consult the [application guide](v2/GUIDE-applications.md).

Report a vulnerability privately using the [disclosure policy](../SECURITY.md).
