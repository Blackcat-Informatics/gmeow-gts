# GTS v2

The [GTS v2 specification](../GTS-SPEC.md) lists all sixteen normative parts and their review status.
Start with [model and wire](P1.md) to read the bytes or [canonical form and reading](P7.md) to compare reader results.

## Informative documents

The [application guide](GUIDE-applications.md) explains which results a caller needs. The
[migration guide](GUIDE-migration.md) covers conversion. The [adoption guide](GUIDE-adoption.md)
and [fixture catalogue](FIXTURES.md) accompany the [conformance corpus](../../vectors/v2/README.md).
