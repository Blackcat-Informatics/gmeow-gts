# Signaler une vulnérabilité

Envoyez un message privé à <security@blackcatinformatics.ca> avec `SECURITY` dans l’objet. Indiquez la partie de la spécification v2 ou la version du logiciel, les conséquences et les étapes de reproduction. Évitez de publier les détails dans un ticket.
