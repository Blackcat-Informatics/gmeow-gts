# Implementing GTS v2

Start with [P1](v2/P1.md) for the wire model and [P2](v2/P2.md) for assigned codes. Use [P7](v2/P7.md) to determine which result to return for a complete, streaming or range read.

Compare the typed results against the [conformance corpus](../vectors/v2/README.md). The [adoption guide](v2/GUIDE-adoption.md) explains what to publish with an interoperability report.
