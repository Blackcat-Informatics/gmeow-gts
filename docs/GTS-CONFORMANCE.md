# GTS v2 conformance

[P7 §5](v2/P7.md#5-conformance) defines the claims a reader or writer can make. Record the revision, input bytes, capacity and typed result when comparing implementations.

The [fixture catalogue](v2/FIXTURES.md) describes the cases. The [corpus instructions](../vectors/v2/README.md) explain how to obtain the bytes and expected results.
